## 통합 절차 (수동으로 다시 할 때)

1. **CSS 추가** — 원본 HTML의 마지막 `</style>` 바로 앞, 또는 `</head>` 직전에 다음을 삽입함
   ```html
   <style id="s5-upgrade"> … s5_css.css 내용 … </style>
   ```
   원본 CSS는 수정하지 않음. 신규 규칙은 전부 `.x` 네임스페이스와 `.sl.v5` 스코프이므로 Ⅰ~Ⅳ장에 영향 없음.

2. **섹션 마크업 교체** — 원본에서 `<section class="sl div" id="sl-d5">` 부터
   `<section class="sl" id="sl-p33"> … </section>` 까지를 통째로 `s5_slides.html` 내용으로 교체함.
   - 원본 파일 기준 **line 255의 `sl-d5` 시작 지점 ~ line 275의 `sl-p33` 종료 지점**
   - `ORDER` 배열, `#dots`, 상세 패널(`#dp`), 목차(`#ix`)의 `data-go="p20"~"p33"` 앵커는 **ID가 동일하므로 수정 불필요**

3. **검증** — `python3 shot.py` 로 15장 전수 렌더 후 린터 통과 확인함
   (겹침·경계 이탈·가로 오버플로 0건, 하단 잔여 여백 1px)

## 개선 내용

### 근본 원인
- 원본 `.fg`가 `align-items:center` 이고 `.exec-grid`만 `flex:1` 이어서, 카드 내부 콘텐츠가 상단에 몰리고 하단이 통째로 비었음
- 원본 `table{min-width:560px}` 전역 규칙이 좁은 칼럼에서 가로 오버플로를 유발했음

### 슬라이드별 개선

| 페이지 | 개선 |
|---|---|
| P20 | 5개 단계 카드 + **누적 공통 기반 계단** + Exit Gate 스트립 + KPI 4종의 4밴드 구조로 재구성함. 계단은 "각 단계가 하나의 공통 기반을 완결" 이라는 헤드라인을 시각적으로 입증함 |
| P21 | 좌측을 **단계별 발주 조건표**(1단계 즉시 승인 / 2~5단계 Gate 조건부)로 전환하고, 우측 Exit Gate를 판정 지표·판정 시점 3열 구조로 확장함 |
| P22~P26 | 상단 KPI 4종(사업비·공수·기간·Gate) 추가, 중앙 칩 클라우드를 **역할 → 적용 제품 → 신규/재사용 구분 매핑표**로 전환, 우측을 **인프라 소요 규모표 + 완료 Gate**로 전환, 하단 범위 제외 밴드 추가함 |
| P27 | 칩 카드 4개를 **5계층 요청 처리 경로 + 4개 횡단 Control Plane** 아키텍처 도식으로 재설계하고 계층별 도입 단계를 명시함 |
| P28 | 좌측을 공용자산 제공 / 단계비 포함 / 별도 조달 **3구분 세그먼트**로 전환하고, 우측 표는 행 높이를 균등 분배함 |
| P29 | 상단 KPI 4종(7개 표준·역할당 1개·기존 4종 유지·중복 0종) 추가, 표가 세로 전체를 채우도록 행 분배함 |
| P30 | 4단계 공급망 통제를 **번호 헤더 + 균등 분배 블록**으로 전환함 |
| P31 | 레인 높이를 고정하고 하단을 **외부 Core Team / 고객 내부 / 레거시 연계 선결조건 3열**로 확장함 |
| P32 | 포함·제외 항목을 블록화하고 증분 단가표 행을 균등 분배함 |
| P33 | 좌측을 사용자 가치 / 공통 기반 / 판정 시점 **3구분 세그먼트**로 전환함 |

### 공통 조정
- 본문 12px, 표 11.4px, 칩 11px 로 상향 (원본 10.1~10.7px)
- `.sl.v5 .fg{align-items:stretch}` 로 도식 영역이 세로를 전부 차지함
- `table{height:100%}` 로 표의 남는 높이를 행에 균등 분배함
- `.x table{min-width:0}` 로 원본 전역 `min-width:560px` 오버플로를 차단함
- 1280 / 1440 / 1600 / 1920 폭 전수 검증 통과함
